# IzziPix - лендинг для фотографов

Статический сайт без сборки: `index.html` + `css/style.css` + `js/main.js` + `assets/`.
Адаптив: десктоп, планшет (<1180px), мобильный (<720px, бургер-меню и нижняя CTA-панель).

## Локальный просмотр
Открыть `index.html` в браузере.

## Публикация на GitHub Pages
1. Создать публичный репозиторий, загрузить в корень все файлы из этой папки.
2. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
3. Через 1-2 минуты сайт доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Где править
- Тексты блоков и модалок - `index.html` (модалки внизу, `div.mbody[data-key=...]`).
- Кнопка «Подробнее» открывает модалку по атрибуту `data-modal="<key>"`.
- Ссылки «Войти», «Написать нам», футер - пока заглушки `href="#"`.
